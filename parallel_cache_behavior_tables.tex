\section{Parallel Cache Behavior}

available on the assigned machine. Following the instructor's suggestion, I
used available replacement events: \texttt{PAPI\_RES\_STL},
\texttt{PAPI\_STL\_ICY}, and \texttt{PAPI\_BR\_PRC}. The program was executed
with 1, 2, 4, 8, and 16 threads, and each thread ran the same task.
